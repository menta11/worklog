# 周报模板

**格式权威。** `SKILL.md` 的压缩规则决定「写什么」，本文件决定「长什么样」。

---

## 骨架

```markdown
<起>-<止>，与周目录同名，如 26.10.12 - 26.10.18
一、本周完成事项

1、<大方向>：
   - <关键进展>
   - <关键进展>

2、<大方向>：
   - <关键进展>

二、下周工作计划

1、<未收尾事项>

三、其它事项

卡点：无
学习/沉淀：
相关链接：
```

---

## 格式约定

| 项 | 写法 |
|---|---|
| 首行 | `<起>-<止>`，与周目录同名（周一到周日），**不带** `#` 标题 |
| 一级章节名 | `一、本周完成事项` / `二、下周工作计划` / `三、其它事项`——固定三个 |
| 一级条目 | `N、<大方向>：`（顿号 + **全角冒号**） |
| 关键进展 | **恰好 3 个空格** + `- `（与日报同款缩进） |
| 条目数 | 大方向 3-5 条，每条下挂 3-5 条关键进展 |
| 末三行 | 依次 `卡点：` / `学习/沉淀：` / `相关链接：`——固定顺序 |
| `相关链接：` | 冒号后换行，下一行写 `<URL> [<链接标题>]`。无链接则整行省略 |

与日报**同构但高一档**：日报按独立交付件铺开，周报按大方向归并。结构一模一样，只是颗粒度上一层。

---

## 换成你自己的格式

把文件放进本目录即可——`reference/` 下的任何文件都会被当作格式依据，**存在自己的样本时以样本为准**（比骨架具体）。
