# 每日文件模板

**格式权威。** `SKILL.md` 的提炼规则决定「写什么」，本文件决定「长什么样」。

一份文件两段：**日报在前，关键帧在后**。日期用周目录同一个口径。

---

## 骨架

```markdown
# <日期，如 26.10.12>

> 今日主线：<一句话点明当天的主战场>

## 一、日报

一、今天完成事项

1、<主题>（<状态或进度>）：
   - <细节>
   - <细节>

2、<主题>：<一句话能说清就直接写在冒号后面>
   - <细节>

二、明天工作计划

1、<未收尾事项>

三、其它事项

卡点：无
学习/沉淀：
相关链接：

## 二、关键帧

<H>：<MM> <描述>
<H>：<MM> <描述>
```

---

## 日报段：格式约定

| 项 | 写法 |
|---|---|
| 一级章节名 | `一、今天完成事项` / `二、明天工作计划` / `三、其它事项`——固定三个，不改字样 |
| 一级条目 | `N、` 开头（**顿号**），N 从 1 连续编号 |
| **主题带状态** | 主题后用**全角括号**注明状态或进度：`（完成6项更新）`、`（MR通过）`、`（完成）`、`（2/4）`。这是稳定约定，不要省 |
| 一句话能说清时 | 写成 `N、<主题>：<描述>`，不再挂细节行 |
| 细节行 | **恰好 3 个空格** + `- `（不是 2 个，不是 Tab） |
| 条目数 | 3-5 条，按**独立交付件**铺开，不按时间线 |
| 末三行 | 依次 `卡点：` / `学习/沉淀：` / `相关链接：`——固定顺序 |
| `相关链接：` | 冒号后**换行**，下一行写 `<URL> [<链接标题>]`。**无链接则整行省略**（不写空的 `相关链接：`） |

---

## 关键帧段：格式约定

| 项 | 写法 |
|---|---|
| 时刻 | `H：MM`，**全角冒号**——写 `9：27` 而不是 `9:27` |
| 一行一条 | 每条独占一行，**不加**项目符号、不加编号 |
| 排序 | 按时间先后 |
| 条数 | 由 `maxKeyframesPerDay` 控制，默认 15 条以内 |

每条**写什么**由 `SKILL.md` 的四类关键帧规则决定（开始做 / 做完 / 遇到卡点 / 跟人对齐），本文件只管**怎么呈现**。

---

## 换成你自己的格式

把文件放进本目录即可——`reference/` 下的任何文件都会被当作格式依据，**存在自己的样本时以样本为准**（比骨架具体）。
