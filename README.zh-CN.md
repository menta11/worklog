# worklog

一个用于自动沉淀工作记录的 Claude Code Skill：从会话记录、Git 提交与文档产出中还原本天做了什么，生成日报与关键帧，周五组装成周报。

> 🌐 [English README](README.md) | 简体中文

## 解决的问题

写日报最费劲的不是写字，是回忆。

而答案其实早就留在机器里了——你和 AI 说过什么、提交了什么、动过哪些文档。尤其是那些随手记下的数字（「24 项问题」「135s→56s」），事后基本想不起来，但它们原封不动躺在 commit message 和文档标题里。

## 解决方案

**worklog** 把这些痕迹自动收拢、去噪、按时间线铺开，交给 AI 提炼成结构化产出。

素材里只有事实、没有结论——哪些值得记、怎么措辞，由 AI 判断。

## 指令

| 指令 | 作用 |
|---------|-------------|
| `/worklog` | 沉淀当天，生成日报 + 关键帧 |
| `/worklog -week` | 生成本周周报（当天未沉淀则先补） |
| `/worklog --backfill 26.10.8-26.10.10` | 回捞历史日期，仅生成关键帧 |

## 实测效果

在一个真实工作日的痕迹上实测：

| 指标 | 结果 |
|--------|-------------|
| 单日提取耗时 | **~2.7 秒** |
| 扫描的本地仓库 | 23 个 |
| 还原出的当天痕迹 | 10 次提交 / 62 条用户输入 / 38 篇文档 |

更值得一提的是**反向印证**：那天手写的关键帧里，有一整块工作完全没有记录，而 worklog 从痕迹里完整还原了它——人会漏记，痕迹不会。

## 安装

将 `worklog/` 目录复制到你的 skills 目录：

- **Claude Code**: `~/.claude/skills/`

首次使用时 skill 会引导你完成配置：确认工作目录、git 身份与数据存放位置。

### 换成你自己的日报格式

`reference/` 是格式模板目录。把自己的模板——或者干脆放几份你过去写的日报——丢进去即可，它优先于默认骨架。放进去的是你自己的材料，记得同步加进 `.gitignore`。

## 结构

```
worklog/

```
